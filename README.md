# Gerenciador de Tarefas em Python

Projeto desenvolvido em Python como parte das atividades formativas da disciplina de DevOps.

## Funcionalidades

- Adicionar tarefas
- Listar tarefas
- Concluir tarefas
- Remover tarefas

## Como executar

É necessário ter o Python instalado.

Execute:

```bash
python app.py
